Privacy Policy

Last updated: October 30, 2026

What this is

Home Assistant Personal Connection is a private connection that the owner uses between their own Home Assistant server and their own Google account. It is used only by its owner and is not offered to the public.

What it accesses

With the owner’s permission, it accesses Google Sheets and Google Drive only to create, read and add rows to a single spreadsheet that the connection itself creates. It does not access any other files, contacts, email or personal information.

How information is used and stored

Information from Google is used only to run the owner’s own home automations. It is stored only on the owner’s own Home Assistant server in the owner’s home. It is not shared with anyone, not sold, not used for advertising, and not transferred to any third party.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove this connection’s access at any time at myaccount.google.com/permissions, or by deleting the integration in Home Assistant.

Contact

For questions, open an issue in this GitHub repository.
